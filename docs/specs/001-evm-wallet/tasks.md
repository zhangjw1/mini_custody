# 001 - Sepolia 原生 ETH 托管钱包任务清单

## 1. 使用说明

- 对应需求：[requirements.md](./requirements.md)
- 对应设计：[design.md](./design.md)
- 本清单只覆盖 Sepolia 原生 ETH，不包含 ERC-20、Solana、Bitcoin 和归集。
- `[P]` 表示在前置任务完成后可以与同阶段其他 `[P]` 任务并行。
- 每个阶段必须通过验收门槛后才能进入下一阶段。

## 2. 第一阶段完成标准

预置用户能够获得平台托管的 Sepolia 地址；外部地址向该地址充值后，系统自动扫描、等待确认并增加余额；用户从 Web 页面提交提币后，系统从该托管地址构建 EIP-1559 交易、分配 Nonce、签名、广播并完成费用结算；进程重启和 API 重试不得产生重复入账或重复提币。

## 12. 后续 Spec

第一阶段完成后按以下顺序继续，不在本任务清单中提前实现：

1. `002-erc20`：Sepolia ERC-20 充值、提币、Gas 补充和归集；
2. `003-solana-wallet`：Solana Devnet SOL 充提，后续扩展 SPL Token；
3. `004-bitcoin-wallet`：Bitcoin Signet BTC 充提和 UTXO；
4. `005-sweeping`：热钱包归集和统一出款；
5. `006-resilience`：自动链重组恢复、对账和故障演练。
